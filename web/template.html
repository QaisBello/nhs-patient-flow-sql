About the data
Synthetic, not real patients. Generated to behave like a hospital extract: winter pressure, quieter weekend discharges, a deprivation gradient and frail older patients coming back.
Coded with NHS Data Dictionary values (admission method, treatment function, discharge destination), ICD-10 diagnoses and OPCS-4 procedures, with spells and consultant episodes as in SUS/HES extracts.

01 · Raw to clean

The extract arrives messy. Every fix is logged.

Duplicate submissions, two date formats, ICD-10 codes with and without the dot, invalid specialty codes and impossible dates. src/clean.py fixes what it can, excludes what it can't, and records both. Both versions are in the repo.

03 · Schema

Tables in the database

Click a table to preview it in the editor. spells is one row per hospital stay; episodes one row per consultant within it. Reference tables decode the NHS and ICD-10 codes.

Synthetic data. No real patient is represented. Patient IDs are random pseudonyms, dates of birth are month and year only, and the provider code XSG is fictional. Population denominators, deprivation deciles and the bed base (170 beds) are part of the simulation.
Code values follow the NHS Data Dictionary; age standardisation uses the 2013 European Standard Population. Built by Qais Adeniji-Bello. Code and data on GitHub.
