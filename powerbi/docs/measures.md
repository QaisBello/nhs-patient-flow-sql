## Beds Occupied at Midnight

*Beds* · table `Spells` · format `#,0` · Patients in a bed at midnight on the last day in context: admitted on or before it and not yet discharged.

```dax
Beds Occupied at Midnight =
VAR _d = MAX ( 'Date'[Date] )
RETURN
    CALCULATE (
        [Spells Count],
        REMOVEFILTERS ( 'Date' ),
        Spells[admission_date] <= _d,
        ISBLANK ( Spells[discharge_date] ) || Spells[discharge_date] > _d

```

## Age-Standardised Rate per 1,000

*Inequalities* · table `Spells` · format `0.0` · Directly age-standardised to the 2013 European Standard Population: band rates weighted by ESP and averaged.

```dax
Age-Standardised Rate per 1,000 =
VAR _bands =
    ADDCOLUMNS (
        VALUES ( 'Age Bands'[age_band] ),
        "@w", CALCULATE ( MAX ( 'Age Bands'[esp2013_weight] ) ),
        "@pop", [Population Count],
        "@events", CALCULATE ( [Emergency Admissions per Year], NOT ISBLANK ( Patients[imd_quintile] ) )
    )
VAR _rated = FILTER ( _bands, [@pop] > 0 )
RETURN
    DIVIDE ( SUMX ( _rated, DIVIDE ( 1000 * [@events], [@pop] ) * [@w] ), SUMX ( _rated, [@w] ) )
```
